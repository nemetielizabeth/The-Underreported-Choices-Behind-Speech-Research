## ***The Underreported Choices Behind Speech Research: A Comparison of Linguistic and Acoustic Processing Decisions for Depression Classification in Voice Diaries***

Analysis code for a study of acoustic and linguistic speech features from daily voice diaries with a test case of depression. 

> **❗Status:** Manuscript in preparation. The full citation will be posted here (expected [September] 2026).

## Repository Structure

| Folder | Contents |
|---|---|
| `Preprocessing/` | Audio cleaning, transcript prep, diary selection |
| `Feature-Extraction/` | openSMILE eGeMAPS, WavLM, LIWC-22, RoBERTa embeddings |
| `Classification/` | Nested cross-validated XGBoost pipeline, SHAP, 95% CIs |

## Requirements

Python 3.13.1 See `requirements.txt`.

## Pipeline

Scripts are organized by stage. Each stage has a Python script and, where the job was run on an HPC cluster, a matching `.sh` SLURM submission script.

### 1. Preprocessing

| Script | Purpose |
|---|---|
| `crop-audios.py` | Trims recordings to a specified duration. Used to test how much audio is needed (e.g. 30s, 1 min, 3 min, full recording). |
| `denoise.py` | Applies DeepFilterNet denoising to the cropped audio. |
| `denoise.sh` | Cluster submission script for `denoise.py`. |

### 2. Feature-Extraction

| Script | Purpose |
|---|---|
| `run-opensmile.py` / `.sh` | Extracts eGeMAPS acoustic features via openSMILE tailored to this project e.g. added word-mapping. |
| `run-opensmile-off-the-shelf.py` | openSMILE extraction using the default configuration. |
| `run-wavlm.py` / `.sh` | Extracts WavLM speech representations. |
| `run-roberta.py` / `.sh` | Extracts RoBERTa embeddings from diary transcripts. |

**LIWC-22 is not included here.** LIWC is proprietary desktop software, not a script. Linguistic features were generated by running transcripts through LIWC-22 directly, and the resulting feature file is treated as an input to the classification stage. The software is available at [liwc.app](https://www.liwc.app).

### 3. Classification

| Script | Purpose |
|---|---|
| `combine-models-multimodal.py` | Merges feature sets into a single input matrix. Any combination of acoustic, linguistic, and demographic features can be selected. |
| `prepare-xgboost-input-file.py` | Attaches labels to the feature matrix and applies the chosen severity cutoff. Defines the label condition used downstream. |
| `run-xgboost.py` | Runs the nested cross-validated XGBoost classifier. |
| `run-xgboost.sh` | Cluster submission script for `run-xgboost.py`. |
